- Rarity and type are no longer typed by hand: adding a card now means searching TCGdex for the set and printing and picking it, with name, number, rarity and type filled in from the catalogue. The existing collection (978 rows) has been backfilled the same way; 22 rows TCGdex couldn't confidently match are listed in `docs/rarity-type-backfill-corrections.md` for manual review. One trade-off: rarity used to double as which foil variant a printing was (non-holo/holo/reversed holo); TCGdex has no such field, so that fact is no longer tracked — the card foil effect now keys off TCGdex's own rarity tier instead.
